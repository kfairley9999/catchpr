catchpr

A comment on a pull request only when a test proves the bug.

If a generated test passes on the base commit and fails on the head, catchpr leaves one comment. Otherwise it stays silent. This page replays recorded transcripts. Nothing here runs on a server.

    Recorded by the catchbench mock run. The page only replays those transcripts. A catch is a test that passed on the base commit and failed on the pull request. If the transcript does not prove that, catchpr stays silent.
